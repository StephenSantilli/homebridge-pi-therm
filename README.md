## Hardware Used
You may be able to substitute certain components. The following are what I used when building this project.

- Raspberry Pi Zero 2W
- SHT-35X temperature & humidity sensor
- A relay board with at least 3 relays
- 18 gauge / 3 conductor thermostat wire
- Waveshare 2in LCD module
